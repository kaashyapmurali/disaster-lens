# xBD imagery in this repository

The images in `assets/` (the README figures and animation) contain crops of xBD satellite imagery and building
annotations, overlaid with this project's predictions.

- Source: xBD dataset, xView2 challenge, https://xview2.org/dataset
- Citation: Gupta et al., "xBD: A Dataset for Assessing Building Damage from Satellite Imagery", CVPR Workshops 2019.
