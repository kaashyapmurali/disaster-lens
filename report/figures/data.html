Data · xBD

xBD pre- and post-event image pairs

Each scene is a 1024 × 1024 pre-event image and a post-event image of the same place, with building outlines and a damage label per building: no damage, minor, major, destroyed. One example per disaster type from the test split.

Class balance

Damage-class shares of labeled buildings. Most buildings are undamaged, so results are reported as recall per class rather than overall accuracy.

Splits

Train and validation split xBD's training set by scene, within each event. The official test split is held out.

Imagery: xBD dataset (xView2 challenge), CC BY-NC-SA 4.0. Example tiles: per disaster type, the test scene with the most damaged buildings, cropped to its densest 448 px window.
