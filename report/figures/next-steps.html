Next steps

In deployment, the damage model needs building footprints that line up with the post-disaster image. With aligned footprints it reaches the known-footprint recall in the results; without them it depends on the detector. In xBD the pairs arrive aligned with their footprints. A real post-disaster image arrives with location metadata only, so aligning it to a pre-event reference is the first step and the main open problem.

Approach to step 1, by available metadata
Case A

Camera pose known

  1. GPS position, altitude, orientation and lens describe the camera completely.
  2. Project rays from the image corners to the ground to get the image's ground footprint: a narrow search area and a first alignment.
  3. Fetch the pre-event reference and building footprints for that area (or use an already matched reference).
  4. Refine with keypoint matching on non-building structure and fit the transform with RANSAC.
Case B

Camera position only

  1. Search radius = GPS error + visibility range (how far the camera can see from its altitude).
  2. Collect candidate reference tiles inside the radius with their building footprints.
  3. Rank candidates with an image embedder (global embeddings, nearest-neighbour search).
  4. Align the best candidates with keypoints on non-building structure and RANSAC; accept only if enough keypoints agree.
In both cases, match only on structure that is not being assessed: roads, bridges, rivers, forest and field edges. Buildings are excluded: they are what the damage model assesses, and they are what the disaster changes. The reference footprints give the mask.
